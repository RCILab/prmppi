# PR-MPPI Project Page

Project page for **Projection-Retraction MPPI: Exact Constraint-Manifold
Control for Manipulators**.

The deployed site is available at <https://rcilab.github.io/prmppi/>. GitHub
Pages serves the repository root from the `master` branch.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.

## Main files

- `index.html`: page content and metadata
- `static/images/fig1.png`: web rendering of the PR-MPPI framework
- `static/pdfs/pr_mppi_framework.pdf`: vector framework figure
- `static/pdfs/pr_mppi_paper.pdf`: paper linked by the **Paper** button
- `static/css/index.css`: shared project-page styling

The page is based on the Academic Project Page Template and retains its
third-party CSS and JavaScript dependencies under `static/`.
